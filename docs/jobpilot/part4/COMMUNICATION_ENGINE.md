# CareerOS JobPilot — Part 4 Communication Engine

**Module**: Multi-Type Candidate Communication Engine  
**Date**: August 13, 2026  

---

## 1. Supported Communication Types

1. **Cover Letter**: `COVER_LETTER` (Target 300–500 words).
2. **Recruiter Email**: `RECRUITER_EMAIL` (Target 100–180 words, neutral greeting safety fallback).
3. **Application Email**: `APPLICATION_EMAIL` (Target 120–220 words, formal resume/cover letter attachment reference).
4. **Outreach & Networking**: `OUTREACH` (Target 50–120 words, platform-safe connection message).
5. **Follow-up Message**: `FOLLOW_UP` (Target 60–150 words).
6. **Application Summary**: `APPLICATION_SUMMARY` (Target 50–100 words).
7. **Application Bundle**: `ApplicationBundle` unified preparation payload.
